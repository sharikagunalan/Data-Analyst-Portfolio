## 1. Kickstarter Crowdfunding Analysis

### 🛠️ Tools Used: 
- SQL
- Excel
- Tableau
- Microsoft Power BI

### 🎯 Problem:
Analyze Kickstarter crowdfunding data to identify factors influencing campaign success and funding performance.

### 🔄 Process:
Cleaned and prepared the dataset using Excel
Performed exploratory data analysis using SQL
Built interactive dashboards in Tableau and Power BI to visualize key metrics

### 💡 Key Insights:
Technology and Design categories show higher success rates
Campaigns with shorter durations tend to achieve better outcomes
Projects with realistic funding goals are more likely to succeed
Most successful campaigns gain strong early traction

### 📊 Dashboard Features:
Total Projects KPI
Success vs Failed Projects
Category-wise performance
Funding trends over time
Goal vs Amount Raised comparison

### ✅ Conclusion:
This project helps stakeholders understand what drives successful crowdfunding campaigns and supports better investment decisions.

## 2. Supply Chain Management Analysis

### 🛠️ Tools Used:
- SQL
- Excel
- Tableau
- Power BI

### 🎯 Problem Statement:
The objective of this project was to analyze supply chain data to identify business trends, monitor key performance indicators (KPIs), and support better operational decision-making. The analysis focused on understanding order performance, sales trends, supplier performance, and delivery efficiency.

### 🔄 Process:
- Collected and explored the supply chain dataset.
- Cleaned and prepared the data using Excel.
- Performed data analysis using SQL to answer business-related questions.
- Created interactive dashboards in Tableau and Power BI to visualize KPIs and trends.
- Identified patterns and summarized insights for business improvement.

### 💡 Key Insights:
- Analyzed sales and order trends across different regions.
- Identified top-performing products and categories.
- Evaluated supplier and delivery performance.
- Monitored important KPIs to support business decisions.

### 📊 Dashboard Features:
- Total Sales
- Total Orders
- Profit Analysis
- Region-wise Performance
- Category-wise Sales
- Monthly Sales Trend
- Top Products
- Interactive Filters and Slicers

### ✅ Conclusion:
This project demonstrates my ability to clean, analyze, and visualize supply chain data using SQL, Excel, Tableau, and Power BI. The dashboards provide actionable insights that can help improve operational efficiency and support data-driven decision-making.
